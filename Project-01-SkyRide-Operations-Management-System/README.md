# SkyRide Operations Management System

## Domain
Travel & Tourism

## Overview
A mobile application designed to assist drivers in managing passenger transportation, trip operations, route execution, boarding activities, communication, payment collection and weather-related disruptions.

## Modules
- Login
- Dashboard
- Manifest Management
- Passenger Management
- Route Management
- Payment Management
- Trip Summary
- Weather Cancellation
